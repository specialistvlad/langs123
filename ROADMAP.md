# Roadmap

The phases of the library: N languages, each explained in N languages. The topic plan, by category
and along the study path, lives in [languages/curriculum.yaml](languages/curriculum.yaml); each
topic's status lives in its `topic.yaml`.

| # | Phase | Delivers | Builds on | Status |
|---|---|---|---|---|
| 0 | Foundations | Conventions, JSON Schemas, topic template | — | done |
| 1 | Web app | Static pages, cheatsheets, level filter, sitemap, publishing | 0 | done |
| 2 | Pilot topics | `en.tenses.simple-tenses` and `es.conjugation.presente-regular`, reviewed in the web app | 1 | done |
| 3 | English topics | Every English topic, by level: A0–A1, then A2, then B1 | 2 | done |
| 4 | Semantic data | The vocabulary of [CONVENTIONS.md](languages/CONVENTIONS.md) §12 in the schemas, the checks and the renderer: every topic names its blocks, marks, structures and features | 3 | done |
| 5 | Explanation languages | Ukrainian, Spanish, Portuguese, French, German, Italian, Polish, Turkish, Indonesian and Vietnamese as explanation languages: the interface, every topic and every example's translation in each; each topic's text in each is a draft until a native speaker approves it | 4 | done |
| 6 | Languages being learned | New languages being learned, each with its foundations from A0, paired with the others through concepts. Spanish comes first: its topics after the Instituto Cervantes curriculum, written in Spanish and explained in English and Ukrainian too, Latin American by default with Spain a switch away | 5 | in progress |
| 7 | Drafts | A language keeps its published data and its drafts side by side; a draft is reviewed before it replaces the published version | 0 | todo |
| 8 | Pronunciation | IPA for words and examples, British and US where they differ, with audio | 4 | todo |
| 9 | Visual explanations | Diagrams rendered from the data, such as tense timelines and paradigm charts | 4 | todo |
